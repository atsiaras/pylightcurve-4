# Citing PyLightcurve

If you use PyLightcurve in your research, please cite:

- **PyLightcurve**: [Tsiaras et al. 2016, ApJ, 832, 202](https://ui.adsabs.harvard.edu/abs/2016ApJ...832..202T/abstract)

Please also cite each of the packages and catalogues that PyLightcurve relies on:

| Package / catalogue | Reference |
|:--|:--|
| [emcee](https://github.com/dfm/emcee) | [Foreman-Mackey et al. 2013](http://iopscience.iop.org/article/10.1086/670067) |
| [ExoTETHyS](https://github.com/ucl-exoplanets/ExoTETHyS) | [Morello et al. 2020](https://iopscience.iop.org/article/10.3847/1538-3881/ab63dc) |
| [Matplotlib](https://matplotlib.org) | [Hunter 2007](https://ieeexplore.ieee.org/document/4160265) |
| [NumPy](https://numpy.org) | [Oliphant 2006](https://archive.org/details/NumPyBook) |
| [SciPy](https://scipy.org) | [Virtanen et al. 2020](https://www.nature.com/articles/s41592-019-0686-2) |
| [Astropy](https://www.astropy.org) | [Astropy Collaboration 2013](https://www.aanda.org/articles/aa/abs/2013/10/aa22068-13/aa22068-13.html) |
| Exoplanet Characterisation Catalogue ([ExoClock project](https://www.exoclock.space)) | [Kokori et al. 2020](https://ui.adsabs.harvard.edu/abs/2020arXiv201207478K/abstract) |
